## 配置与保存边界

25 个可见节与 `Config.dict` 的可见键保持测试约束，表单继续从同一 Schema 自动渲染。隐藏兼容项保留原 Schema 行为。当前故事的 10 个设定键写入故事数据库，`storyDefaults` 用于新故事默认档案。

保存先按节合并和重置，再校验整份 Config，最后调用 Koishi scope 更新。普通保存由框架判断重载需要，强制保存传递 reload=true。RPC 管理权限保持 authority=3；读取保持 authority=1。强制重载后的即时回读如果失败，页面说明“配置已保存，重新读取失败”，并提供重试。

模型密钥按连接 ID 保留，修改连接 ID 后应填写实际密钥或留空。所有 API Key 都以 Schema 的 secret 角色识别，服务端预校验和读写均不输出真实密钥。

## 交付与使用

`lib/` 与 `client-dist/` 为构建产物。使用工作区运行插件时重载 HDSI，再刷新 Console；使用安装包时，安装包含本次改动的新包后再重载与刷新。首次验证若浏览器仍展示旧样式，可强制刷新缓存。

本次集中修复界面、说明与配置读写边界，未引入新的模型调用、联网探活或后台轮询。概览条目统计采用数据库聚合，移除模型展示字符串解析，并减少重复读取主故事。考据案头当前继续展示聚合统计。
