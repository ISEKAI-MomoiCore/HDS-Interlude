# README 视觉资产

这套平面海报沿用最新版一条龙 HTML 的视觉语言：纸面留白、大字、细线和几何方块。

- 纸面 `#f7f8fa`、墨色 `#111827`、蓝色 `#2563eb`、青绿 `#14b8a6`；橙色 `#ff5c33` 来自向导暗色主题。
- `*.svg` 是可编辑源文件；`*.png` 是 README 实际引用的 2 倍分辨率静态图片。
- 图片不含脚本，不读取外部数据，不依赖外部字体或徽章服务。
- 徽章只描述核实过的项目元信息，不表示实时统计、测试或运行状态。
- 发布新版本时，同步更新 `version.svg` 的版本文字与标题，导出 `version.png`，并更新根 README 的对应替代文字。
- 修改 SVG 后，以浏览器按 SVG 声明尺寸、2 倍像素比例重新导出 PNG；保留完整画布，不加边框或阴影。
- 这些资产通过 `package.json` 的 `docs/assets/readme/**` 一起进入后续安装包，避免包内 README 的本地图片缺失。
