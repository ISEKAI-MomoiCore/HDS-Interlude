# 模型特化（Model Specialization）

版本：1.0.1-rc12-cev.4 起。设计依据：《模型横向对比-HDSI特化资料集》（EQ-Bench 创作榜/长文榜/15 维能力雷达/人格心理测量）；特化块全文与数据依据见仓库外文档 `C:\dev\model-research\`。

## 是什么

同一个 rc12 固定合约对不同能力的模型代价不同：flash 级模型被 ~26K 字符合约压垮（注意力预算不足），强模型又能吃满细节。模型特化让主叙事合约**按你手动选择的档位**切换规模，并按模型家族套用针对其量化弱项的最小偏移块。

## Console 配置（两个下拉，都在【必填 2】模型中心内）

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `model.specialization` | `off` | **档位（手动）**。off=rc12 原样完整合约，行为与未特化版本完全一致；lite=精简合约；standard=标准合约；full=完整合约 |
| `model.specializationFamily` | `auto` | **家族**。auto 按模型名识别（只决定套哪套特化块，不决定档位）；模型名识别不出时（中转自定义别名）在此显式指定；generic=只换档位不套家族块 |

没有自动切换：档位永远由你显式选择，改配置后**下一回合生效**（无需重载——Koishi 配置变更自动触发插件重载，档位在每次请求构建时按当前服务商解析，故障切换到别的家族合约也会跟随）。档位变化时日志输出 `模型特化已切换 档位=… 家族=… 探测=…`。

## 三档合约

| 档位 | 内容 | 适用 |
| --- | --- | --- |
| **lite** | 15 块核心：生活剧本宣言 + 家族长度块 + 打字消息块 + JSON 合约 + 时钟/未读 + phase 指令 + **content-only 传输协议** + 防幻觉三件套（不虚构消息/所有权标签/事件来源）+ 管理注记 + 用户配置段。裁掉：say 标记教学、知识证据框架、跨渠道路由、侧端字段教学 | Gemini flash 系、Grok 全系、GLM-4.x |
| **standard** | rc12 全量合约，仅传输协议块替换为 content-only 精简版 | Gemini Pro、GLM-5+、Kimi、DeepSeek V4 |
| **full** | rc12 原样（say 锚点协议 + 完整规则集） | Claude、GPT-5.x、以及**所有未识别模型**（保守回退，中转别名不静默改变行为） |

**侧端提示词跟随同一档位**：lite 时压缩与时间导演提示词切换为精简版（压缩 JSON 裁掉 knowledge/workingDetails/episodeTags 等重 schema；时间导演保留五条核心规则）。standard/full 的侧端提示词不变。不单独开侧端配置项——档位描述的是模型能力预算，同一模型跑所有任务能力相同。

## off 档承诺

`off`（默认）下 `systemPrompt` 输出与 rc12 **字节一致**（有测试锁定），特化完全不生效。所有家族块只替换/新增，不改基线块文本。

## 三层分工

- **英文固定合约（本功能）**：纪律与协议——时间规则、传输镜像、防幻觉、所有权
- **中文 mainPrompt**（Console 每故事可配）：行为重心——各模型配套版本见 `C:\dev\model-research\模型特化主提示词集.md`
- **stylePrompt**：文风

三层刻意不重叠：合约管"必须怎样"，mainPrompt 管"重心在哪"，style 管"写起来什么味道"。同一指令写两遍会稀释权重。

## 已知边界

- 推断用服务商的 model/id/label 字符串；中转完全改写模型名时落到 full 档（保守但不特化），在 provider 的 label 带上真实模型名或用 specializationFamily 显式指定。
- 家族识别覆盖 claude/gemini(含 flash)/gpt/grok/kimi/glm/deepseek；qwen 等其余家族走 generic。
- lite 档不支持跨渠道路由（合约已裁剪）；群聊回合正常（groupReply 通道保留）。
